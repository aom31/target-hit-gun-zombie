# microSD สำหรับ DFPlayer ในหุ่น (เสียงตอนยิงโดน)

โฟลเดอร์นี้คือสิ่งที่ต้องอยู่บนการ์ด microSD ของ**หุ่นแต่ละตัว** (ทำ 2 ใบ ไฟล์เหมือนกัน)

```
01/001.mp3   เสียงทดสอบ: คำรามสั้น เสียงต่ำลง
01/002.mp3   เสียงทดสอบ: คำรามเสียงสูงขึ้น
01/003.mp3   เสียงทดสอบ: แยกเขี้ยวสั้น ๆ
01/004.mp3   ผู้ชายครางเจ็บ (0.7 วิ) ตัดจาก source/dragon-studio-male-groan-of-pain-357971.mp3
01/005.mp3   ซอมบี้ร้องเจ็บ (1.4 วิ) จาก source/freesound_community-zombie-pain-1-95166.mp3
```

- 001–003 สังเคราะห์ด้วย `python3 tools/make_test_hit_sounds.py` (ไม่มีลิขสิทธิ์ของคนอื่น)
- 004–005 มาจากไฟล์ใน `source/` (ดาวน์โหลดจาก Pixabay ตามชื่อไฟล์ ก่อนส่งงานลูกค้าให้เช็กสัญญาอนุญาตในหน้าดาวน์โหลดอีกครั้ง)
  ตัดช่วงเงียบหัวไฟล์ แปลงเป็นโมโน 128 kbps และปรับความดังให้ใกล้กันทุกไฟล์ `source/` ไม่ถูก copy ลงการ์ด
- ระบบสุ่มเล่น 1 ใน 5 ไฟล์ทุกครั้งที่ยิงโดน (ค่าเริ่มต้นของ "จำนวนไฟล์เสียงยิงโดน" = 5)

## ใส่ลงการ์ด
```
make sd-card SD=/Volumes/ชื่อการ์ด
```
คำสั่งนี้ copy โฟลเดอร์ `01` ลงการ์ด แล้วลบไฟล์ `._*` ที่ macOS แอบสร้าง (DFPlayer อาจนับไฟล์พวกนี้ด้วย)

## เปลี่ยนเป็นเสียงจริง
- วางไฟล์ทับใน `01/` โดยตั้งชื่อ `001.mp3`, `002.mp3`, … **เรียงต่อกัน ห้ามข้ามเลข** (สูงสุด 20 ไฟล์)
- MP3 โมโน ยาว 0.5–1.5 วินาที ตัดช่วงเงียบหัวไฟล์ออก
- หน้าผู้ดูแล → ฮาร์ดแวร์ → **จำนวนไฟล์เสียงยิงโดน** = จำนวนไฟล์ (ระบบสุ่มเล่น 1 ไฟล์ต่อการยิงโดน)
- ในโหมด demo (`make demo`) เบราว์เซอร์จะเล่นไฟล์ในโฟลเดอร์นี้แทนลำโพงหุ่น ใช้ฟังเสียงก่อนใส่การ์ดได้
