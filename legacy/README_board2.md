# Target Competition Dashboard

ระบบต้นแบบแข่งขันยิงหุ่น รองรับหุ่น 1–10 ตัวในแต่ละรอบ (เลือกเปิดได้ไม่เท่ากัน), ผู้เล่นมากกว่า 2 คน, 5 โซนต่อหุ่น, คะแนนต่างกันตามโซน และเวลาโบนัสเมื่อโดนเป้าคะแนนสูง

## กติกาในเวอร์ชันนี้
- ผู้เล่นแต่ละคนเริ่มด้วยคะแนน 0 และเวลาตั้งต้นตามค่าที่ตั้ง (ค่าเริ่มต้น 10 นาที)
- ผู้เล่นแต่ละคนมีนาฬิกาของตัวเอง นับถอยหลังอิสระ
- เมื่อยิงโดนโซน จะเพิ่มคะแนนและบวกเวลาโบนัสตามกติกาโซน
- เวลาโบนัสเพิ่มให้เฉพาะผู้เล่นที่ยิงโดน
- เกมจะหยุดรับ Hit เมื่อผู้เล่นหมดเวลา หรือเมื่อไม่มีผู้เล่นที่ยังเล่นอยู่
- เลือกหุ่นที่เปิดใช้งานได้เป็นรายรอบ
- ค่าเริ่มต้น: โซน 1 = 10 คะแนน + 30 วินาที, โซน 2 = 8 + 20 วินาที, โซน 3 = 6 + 10 วินาที, โซน 4 = 4 + 5 วินาที, โซน 5 = 2 + 0 วินาที
- แก้กติกาคะแนนและเวลาโบนัสได้ก่อนเริ่มเกม

## เปิด Dashboard บน Mac
```bash
cd dashboard
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```
เปิด http://127.0.0.1:5000

## Event format จากระบบยิง
หนึ่ง JSON ต่อหนึ่งบรรทัด:
```json
{"event":"HIT","player_id":"P1","target_id":2,"zone_id":4,"peak_adc":620,"peak_delta":360,"timestamp_ms":123456}
```
- `player_id` ต้องตรงกับ ID ที่ระบบกำหนดในรอบนั้น (`P1`, `P2`, ... ตามลำดับรายชื่อ)
- `target_id` เป็น 1–10
- `zone_id` เป็น 1–5
- Hit จะถูกปฏิเสธถ้า target ไม่ได้เปิดใช้ในรอบนี้, player ไม่ได้อยู่ในเกม, ผู้เล่นหมดเวลา หรือเกมไม่ได้เริ่ม

## ระบุว่าใครเป็นคนยิง
Dashboard ไม่สามารถทราบตัวผู้ยิงจาก Piezo อย่างเดียว ต้องมีวิธีระบุตัวผู้เล่น เช่น:
1. ผู้เล่นแต่ละคนมีปุ่ม/อุปกรณ์ยิงที่ส่ง `player_id` ของตัวเอง
2. มี RFID/QR/ปุ่มเลือกผู้เล่นที่สถานียิง แล้ว controller แนบ player_id ให้ event
3. ถ้าเป็นการยิงทีละคน ให้เลือกผู้เล่นที่สถานีควบคุมก่อนเริ่มช่วงยิง (ไม่เหมาะกับการยิงพร้อมกันหลายคน)

## หลายหุ่นและหลายโซน
Dashboard รองรับหลาย Serial port และรับ event จากหลายบอร์ด แต่ firmware เดิมที่อ่าน Piezo เพียงจุดเดียวต้องปรับให้ส่ง `target_id`, `zone_id`, `player_id` ที่ถูกต้อง การมี Dashboard อย่างเดียวไม่ได้ทำให้แยกโซนหรือรู้ผู้ยิงได้อัตโนมัติ

## หมายเหตุ
- เป็น prototype: คะแนน/ประวัติไม่บันทึกถาวรและหายเมื่อรีสตาร์ตแอป
- เวลาคงเหลือเป็นรายผู้เล่น ไม่ใช่เวลารอบรวม
- เวอร์ชันนี้เป็น local-only ที่ 127.0.0.1
- ปิด Serial Monitor ของ PlatformIO ก่อน Dashboard เปิดพอร์ตเดียวกัน
- ตรวจสอบวงจรป้องกัน GPIO ของ Piezo ก่อนทดสอบแรงกระแทกจริง
