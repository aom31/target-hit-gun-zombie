# Target Range

ระบบนับคะแนนยิง BB gun ใส่หุ่น 2 ตัว ตัวละ 5 โซน ระบบสุ่มเปิดไฟที่โซนเป้า ผู้เล่นต้องยิงให้ทันก่อนไฟดับ และควบคุมทุกอย่างผ่านมือถือ

```text
 [หุ่น 1: Piezo×5 + ไฟ×5]──┐ ESP-NOW              WiFi
 [หุ่น 2: Piezo×5 + ไฟ×5]──┼────────── [HUB] ─────────── 📱 http://192.168.4.1
                           └ 12V ─────── adapter 12V
```
ขั้นตอนจริงที่สนาม
เสียบปลั๊ก hub และหุ่น รอไฟหน้ากล่อง hub เป็นสีเขียว (ประมาณ 10–20 วินาที)
มือถือต่อ WiFi TARGET-RANGE รหัส targetrange หรือสแกน QR ① บนป้ายที่พิมพ์จากหน้าผู้ดูแล
หน้าเกมเด้งขึ้นมาเอง ถ้าไม่เด้ง ให้เปิด http://192.168.4.1 หรือสแกน QR ②
ตั้งค่าครั้งเดียวหลังติดตั้ง (หน้าผู้ดูแล → WiFi, PIN และระบบ)

เปลี่ยนรหัส WiFi และ PIN จากค่าเริ่มต้น แล้วกดรีสตาร์ท hub
จากนั้นพิมพ์ป้าย QR ใหม่ เพราะ QR ฝังรหัส WiFi ไว้
ช่อง WiFi (1–13) ปกติไม่ต้องแก้ ถ้าสนามมี WiFi อื่นเยอะแล้วเกมกระตุก ให้ลองเปลี่ยนช่อง หุ่นจะหา hub เจอเองในช่องใหม่

ต่อได้กี่คน
ส่วน	ขีดจำกัด	ที่มา
ต่อ WiFi ของ hub	6 เครื่อง (เครื่องที่ 7 ต่อไม่ติด)	ผมตั้งไว้ใน firmware (main.cpp:15)
ช่องส่งข้อมูลสดไปหน้าเว็บ	8 การเชื่อมต่อ	ค่าของ library เว็บ
ฮาร์ดแวร์ ESP32 รองรับสูงสุด	10 เครื่อง	ข้อจำกัดของชิป
ผมตั้งไว้ 6 เพื่อเผื่อหน่วยความจำและเวลาของบอร์ดให้งานจับการยิง ซึ่งต้องเร็วที่สุด สนามที่ยิงได้ทีละ 1–2 คน 6 เครื่องก็พอสำหรับผู้เล่น 2 คนกับเพื่อนที่ยืนดู ถ้าอยากเพิ่ม ปรับเป็น 8 ได้อย่างปลอดภัย (ต้องปรับทั้งสองส่วนให้เท่ากัน) แต่ไม่แนะนำเกิน 8

ทำไมทุกเครื่องเห็นเหมือนกัน
hub เป็นที่เก็บข้อมูลเพียงที่เดียว มือถือไม่ได้คำนวณคะแนนเอง แค่แสดงสิ่งที่ hub ส่งมา


หุ่นโดนยิง → hub ตัดสินคะแนน → hub ส่งผลให้ทุกเครื่องพร้อมกัน
                                  ├─ มือถือผู้เล่น 1
                                  ├─ มือถือผู้เล่น 2
                                  └─ มือถือคนดู ...
ต่อกันค้างไว้ตลอด (WebSocket): hub ไม่ต้องรอให้มือถือถามก่อน มีอะไรเปลี่ยน hub ส่งออกไปเองทันที
ทุกการยิงส่งถึงทุกเครื่องพร้อมกัน: ยิงโดน ยิงผิดจุด หรือเป้าหมดเวลา ทุกเครื่องเห็นคะแนนขึ้นในเวลาไม่ถึง 0.1 วินาที
ส่งสถานะเกมเต็ม ๆ ซ้ำทุก 1 วินาที (เวลาที่เหลือ คะแนน หุ่นออนไลน์ไหม) ถ้ามือถือเครื่องไหนพลาดข้อความไป วินาทีถัดไปก็ตรงกับเครื่องอื่นอีกครั้ง
นาฬิกาตรงกัน: hub ส่ง "เกมจะจบที่เวลาไหน" ให้ทุกเครื่องนับถอยหลังเอง ตัวเลขเวลาบนทุกจอจึงตรงกัน
มือถือที่เข้ามาทีหลัง หรือหลุดแล้วต่อใหม่: hub ส่งสถานะปัจจุบันให้ทันที ถ้าเกมจบแล้วก็ส่งผลเกมล่าสุดให้ด้วย จึงเปิดมากลางเกมแล้วดูต่อได้เลย
อันดับและประวัติ: ทุกเครื่องดึงประวัติจากไฟล์เดียวกันบน hub แล้วโหลดใหม่ทุกครั้งที่เกมจบ อันดับจึงตรงกันทุกเครื่อง


- **2 โหมด**: เล่นคนเดียว (ยิงทั้ง 2 หุ่น) และเล่น 2 คน (คนละหุ่น ลำดับเป้าเหมือนกัน)
- **3 ระดับความยาก**, คะแนนต่างกันตามโซน, ยิงผิดจุดไม่ได้คะแนน, สรุปผลและประวัติบนมือถือ
- **จูนเซนเซอร์จากมือถือ**: ทดสอบ crosstalk แบบนำทางทีละขั้น แล้วระบบเสนอ threshold ให้
- **เสียง**: นับถอยหลัง 5 วินาทีบนมือถือเครื่องที่กด START และเสียงที่หุ่นเมื่อยิงโดน (DFPlayer Mini + ลำโพง)

## เริ่มต้นใช้งาน

```bash
make test     # unit tests (36 ข้อ)
make demo     # ลองหน้าเว็บด้วย hub จำลอง: http://localhost:8000/web/?demo
make build    # compile firmware ทั้ง 3 ตัว
make flash-hub  PORT=/dev/cu.usbserial-XXXX
make flash-node PORT=/dev/cu.usbserial-XXXX   # หุ่น 2: ต่อ GPIO27 ลง GND
```

**ขั้นตอนทั้งหมด ตั้งแต่ทดสอบระหว่างรออุปกรณ์จนถึงติดตั้งในสนาม อยู่ใน [NOTES.md](NOTES.md)**
